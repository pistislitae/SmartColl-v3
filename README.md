# SmartColl Clean — Public Actions

Repository ini hanya menjalankan GitHub Actions manual untuk:

- build APK SmartColl dari source private;
- deploy source private ke Cloudflare Pages.

Source aplikasi, dokumentasi deployment, konfigurasi, dan data operasional tidak disimpan di repository public ini.

Jalankan melalui **Actions → pilih workflow → Run workflow**. Seluruh petunjuk setup dan keamanan berada di repository private `pistislitae/SmartColl-v3-Priv`.
